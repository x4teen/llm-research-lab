# LLM Research Lab

A 20-week research project investigating the capabilities,
limitations, reasoning, and tool use of open-source LLMs.

## Research Questions

1. What can LLMs accomplish without extended reasoning?
2. When does deliberate reasoning improve accuracy?
3. Which failures persist despite reasoning?
4. When do external tools improve reliability?

## Environment

- Python and Jupyter
- Ollama
- Qwen3 4B
- DeepSeek-R1
- NVIDIA cloud GPU

## Experimental Phases

1. Information Extraction
2. Classification
3. Factuality and Hallucination
4. Long-Context Retrieval
5. Chain-of-Thought Reasoning
6. Self-Consistency
7. Planning and Constraint Satisfaction
8. Tool Use
9. Independent Research Project

## Reproducibility

Each experiment records prompts, model versions,
datasets, inference settings, results, and evaluation metrics.
